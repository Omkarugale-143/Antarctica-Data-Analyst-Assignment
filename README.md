CO₂ Emission Analysis & Sustainable IT Strategies
Author: Omkar Ugale
This repository contains the complete solution for the Data Analyst Assignment given by Antarctica Global, focusing on global emission trends, digital infrastructure sustainability, and actionable IT decarbonization strategies.
🚀 Project Overview
This project analyzes global CO₂ emissions from 1980–2023 using the Our World in Data (OWID) dataset.
It also includes synthetic benchmark data for:

Cloud region carbon intensity
Data centre emission estimates for 2024
The objective is to understand current emission patterns, project future trends, and propose Sustainable IT strategies relevant to enterprises like Antarctica Global.

📊 Key Research Questions

How will global emissions evolve over the next 5 years?
How does cloud-region carbon intensity affect AI/data workloads?
How do data centre emissions compare with national emissions?
Which Sustainable IT strategies deliver the highest impact?
